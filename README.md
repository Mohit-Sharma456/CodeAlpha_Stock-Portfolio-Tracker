# 📈 Stock Portfolio Tracker - Python Internship Project

## 📌 Project Overview

The Stock Portfolio Tracker is a simple Python-based application developed as part of an internship project. The program allows users to track their stock investments by entering stock names and quantities. Using predefined stock prices stored in a dictionary, the application calculates the total investment value of the portfolio.

The project is designed to demonstrate fundamental Python programming concepts, including dictionaries, user input handling, arithmetic calculations, and file handling. Users also have the option to save their portfolio summary to a TXT or CSV file for future reference.

## 📊 How It Works

1. The program stores stock prices in a predefined dictionary.
2. The user enters a stock symbol and quantity.
3. The application calculates the value of each stock holding.
4. The total portfolio investment value is calculated.
5. Results are displayed on the screen.
6. Optionally, the portfolio summary can be saved to a TXT or CSV file.
